# Staged shared SDK CI (MAGE-1726)

Everything under `ci-staging/github/` is the intended end state of the matching path under `.github/` (`ci-staging/github/shared/notify-slack/action.yml` becomes `.github/shared/notify-slack/action.yml`). Each staged workflow is a full replacement for the existing file. `ci-staging/DELETE` lists the `.github/` files to remove after the move. The branch adds composite actions under `.github/shared/` (`notify-slack` moved unchanged from `.github/actions/notify-slack`, `promotion-check` with glob `bump-files`, `pr-target-check`, `linear-release-sync`, `stale`, `remove-deploy-label`), two callable workflows (`release-preflight.yml`, `rel-branch-core.yml`) and the contract in `.github/shared/README.md`. It also switches RN's own workflows to use them: `publish-release.yml`, `rel-branch.yml` (the `pin` job stays), `publish-sdk.yml`, `publish-example.yml`, `doc-bot.yml`, `pr-target-check.yml`, `stale.yml` and the new `promotion-check.yml`. To apply it, copy `ci-staging/github/.` over `.github/`, delete the paths in `DELETE`, then delete `ci-staging/`.
